# Homelab Setup

This repository documents my personal homelab build, starting with a full home network infrastructure upgrade. Each subfolder contains detailed setup documentation for a specific component of the lab.

>  Earlier setups like the dual-boot system are archived for reference but have since been replaced by a Proxmox-based virtualization environment for scalability and centralized management.
