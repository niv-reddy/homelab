# 🏡 Home Network Upgrade

This subproject documents the complete upgrade of my home network from a basic ISP router/modem combo to a fully wired Eero mesh system. It includes Ethernet wall jack activation, cable crimping, switch installation, and Eero device setup.

## 📄 Documentation

- [`Homelab_Setup_Documentation_v1.pdf`](./Homelab_Setup_Documentation_v1.pdf): Full write-up covering motivation, setup, challenges, configuration, and future plans.
- [`topology/Flow.drawio.png`](./topology/Flow.drawio.png): Visual network topology diagram showing final layout.

## 🧠 Summary

- All access points use **wired backhaul** for maximum stability.
- ISP gateway placed in **bridge mode** to let Eero handle routing.
- Structured and documented with future homelab expansion in mind.
