# 🏡 Home Network Upgrade

This subproject documents the upgrade of my home network from a basic ISP gateway to a fully wired Eero mesh system with structured Ethernet, crimped ports, and centralized switching.

## 📄 Included

- **[Homelab_Setup_Documentation.pdf](./Homelab_Setup_Documentation.pdf)** – Full write-up covering motivation, layout, configuration, challenges, and future plans.
- **[topology/network_topology.png](./topology/network_topology.png)** – Visual diagram of the final wired mesh setup.

## 💡 Key Notes

- Xfinity gateway placed in **bridge mode**
- Main **Eero Pro 6** routes entire network
- **Three wired Eero 6+ nodes** using pre-run Ethernet lines
- Clean cable management and organized patch panel
- Added **MoCA adapter** to leverage coaxial cable for wired Ethernet in bedroom
